# VLS Warfare 1.3.1

Minecraft 1.20.1 / Forge 47.2.0 以上 / Superb Warfare 0.8.0 以上向けのVLS・レーダー追加Modです。

## 導入

1. Minecraft 1.20.1にForge 47.2.0以上を導入します。
2. Superb Warfareと、その必須依存Modを導入します。
3. 古いVLS WarfareのJARを削除し、`vlswarfare-1.3.1.jar`をクライアントとサーバー双方の`mods`フォルダへ入れます。

## 追加内容

- 攻撃ミサイル（対地・対車両）
- 迎撃ミサイル（対ミサイル・対航空機）
- 核ミサイル（大威力・広範囲爆発）
- 4×4ブロック・16セルVLS
- ミサイル管制装置
- データリンク端末（手動リンク用）
- 半径10,000ブロックの戦術レーダー
- 独自3Dモデル、独自テクスチャ、飛翔姿勢・回転・噴炎アニメーション
- 低速垂直射出、ロケット点火、段階加速、煙・噴炎トレイル
- Superb Warfare車両・航空機・ミサイルの捕捉と攻撃
- Superb Warfare専用ダメージ種別・車両HP・周辺爆風ダメージへの直接連携
- エンティティ目標と地上座標目標
- 飛翔線分による半径5ブロック以内の近接起爆と移動目標の未来位置予測

## 操作方法

1. レーダー、管制装置、VLSを128ブロック以内へ設置します。VLSは設置時に4×4ブロックへ展開されるため、平坦な空き地が必要です。
2. データリンク端末を持って管制装置を右クリックし、接続先の管制装置を選択します。
3. 同じ端末でレーダーを右クリックして登録します。続けて各VLSを右クリックし、使用するVLSだけを個別登録します。
4. 同じ設備をもう一度右クリックするとリンク解除になります。別の管制装置を選択して設備を右クリックすると、その設備は新しい管制装置へ移管されます。
5. 攻撃ミサイルまたは迎撃ミサイルを持ってVLSのいずれかの区画を右クリックすると装填します。最大16発です。
6. VLSをShift＋右クリックすると、最後に装填した弾を1発取り出します。
7. レーダーを右クリックし、画面上の点をクリックして目標を捕捉します。
   - 赤: ミサイル
   - 黄: 航空機
   - 水色: Superb Warfare車両
8. 管制装置を右クリックし、手動登録したレーダーとVLSの状態を確認します。
9. 「攻撃ミサイル 発射」「迎撃ミサイル 発射」「核ミサイル 発射」から弾種を選びます。
10. 地上を直接攻撃する場合はX/Y/Zを入力し、「通常弾 座標攻撃」または「核弾頭 座標攻撃」を押します。

## Config

初回起動後に`config/vlswarfare-common.toml`が作成されます。

- `speedBlocksPerSecond`: ミサイル速度。既定値200ブロック/秒
- `launchSpeedBlocksPerSecond`: VLS射出直後の速度。既定値8ブロック/秒
- `verticalLaunchTicks`: 垂直に低速上昇する時間。既定値16tick（0.8秒）
- `accelerationTicks`: 巡航速度まで加速する時間。既定値24tick（1.2秒）
- `rangeBlocks`: レーダー半径。既定値10,000ブロック
- `linkRangeBlocks`: レーダー・管制装置・VLSのリンク距離。既定値128ブロック
- `attackDamage`: 攻撃ミサイル直撃ダメージ
- `interceptorDamage`: 迎撃ミサイル直撃ダメージ
- `nuclearDamage`: 核ミサイル直撃ダメージ。既定値2,000
- `nuclearExplosionPower`: 核爆発の威力・半径。既定値24（大きくするとサーバー負荷が増えます）
- `superbWarfareVehicleDamageMultiplier`: Superb Warfare車両専用のダメージ倍率。既定値6倍

`vlswarfare-common.example.toml`も同梱しています。

## 注意

- レーダーが検出できるのは、サーバー上で読み込まれているエンティティです。
- 10,000ブロック範囲は広いため、大規模サーバーでは範囲を下げると負荷を抑えられます。
